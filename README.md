# Basecamp - User Authentication & Travel Portal

A responsive, secure authentication and user management system built with HTML, CSS, and vanilla JavaScript featuring real-time form validation, password visibility toggles, and local storage integration.

---

## ✨ Features

* **Secure Authentication System:** Complete user registration and sign-in flow utilizing browser `localStorage` to verify registered accounts.
* **Real-Time Client-Side Validation:** Instant error feedback for required fields, valid email structures, 10-digit phone numbers, alphabetic city inputs, and strict password criteria.
* **Password Visibility Toggle:** Interactive show/hide eye icons integrated into password and confirm password fields to reduce input errors.
* **User Profile & Session Management:** Dynamic user details page (`userdetails.html`) displaying logged-in profile data with secure session logout handling.
* **Responsive Glassmorphism UI:** Modern frosted-glass card layouts styled with Flexbox and media queries for seamless adaptation across mobile, tablet, and desktop viewports.

---

## 🛠️ Built With

* **HTML5** – Semantic markup and form structuring
* **CSS3** – Modern styling, Flexbox, backdrop filters (`backdrop-filter: blur`), and media queries
* **Vanilla JavaScript** – Form validation logic, DOM manipulation, and `localStorage` data handling
* **FontAwesome** – Iconography for interactive password visibility toggles
